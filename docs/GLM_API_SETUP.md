# GLM-4.5V API 集成说明

## 概述
本项目已集成GLM-4.5V多模态大模型API，用于智能分析用户上传的舞蹈视频，提供专业的评分和改进建议。

## 配置步骤

### 1. 获取API密钥
1. 访问 [智谱AI开放平台](https://open.bigmodel.cn/)
2. 注册账号并完成实名认证
3. 创建API密钥
4. 复制您的API密钥

### 2. 配置API密钥
编辑 `src/config/api.ts` 文件：

```typescript
export const API_CONFIG = {
  GLM: {
    API_KEY: 'your-actual-api-key-here', // 替换为您的真实API密钥
    // ... 其他配置
  }
};
```

### 3. 安装依赖
确保已安装必要的依赖包：

```bash
npm install react-native-fs react-native-image-picker
# 或
yarn add react-native-fs react-native-image-picker
```

## 功能特性

### 视频分析能力
- ✅ 节拍感和音乐配合度分析
- ✅ 动作准确性和流畅性评估
- ✅ 身体协调性和平衡感检测
- ✅ 表情和舞台表现力评价
- ✅ 综合评分 (0-100分)

### 技术特性
- ✅ 自动重试机制 (最多3次)
- ✅ 请求超时控制 (30秒)
- ✅ 错误处理和用户友好提示
- ✅ 支持多种视频格式 (MP4, MOV, AVI, MKV)
- ✅ 文件大小限制 (最大50MB)

## API调用流程

```
用户选择视频 → 格式验证 → 转换为Base64 → 调用GLM API → 解析结果 → 显示分析报告
```

## 故障排除

### 常见问题

1. **API密钥无效**
   - 检查API密钥是否正确配置
   - 确认账户余额充足
   - 验证API密钥权限

2. **网络请求失败**
   - 检查网络连接
   - 确认防火墙设置
   - 尝试使用代理

3. **视频格式不支持**
   - 确保视频格式为MP4、MOV、AVI或MKV
   - 检查文件大小是否超过50MB限制
   - 验证视频文件完整性

4. **分析结果异常**
   - 检查视频内容是否清晰
   - 确保视频包含舞蹈动作
   - 验证视频时长不超过5分钟

## 安全注意事项

1. **API密钥保护**
   - 不要将API密钥提交到版本控制系统
   - 使用环境变量存储敏感信息
   - 定期轮换API密钥

2. **用户隐私**
   - 确保用户同意视频分析
   - 不要存储用户视频内容
   - 遵守相关隐私法规

3. **使用限制**
   - 设置合理的调用频率限制
   - 监控API使用量
   - 实施用户级别的使用配额
