## 设计要求

### 背景图片设计要求：
1. **色彩**: 使用渐变色彩，包含紫色、蓝色、粉色、橙色等
2. **形状**: 几何形状，圆形或椭圆形的色块
3. **效果**: 模糊渐变效果，营造梦幻感
4. **透明度**: 支持叠加半透明遮罩层

### 参考色彩：
- 主紫色: #667eea
- 深紫色: #764ba2  
- 粉色: #f093fb
- 红色: #f5576c
- 蓝色: #4facfe

## 临时解决方案

在获得实际图片之前，可以使用以下方案：
1. 使用CSS渐变背景替代图片
2. 使用在线图片生成工具创建渐变背景
3. 使用免费的渐变背景图片资源

## 图片优化建议

1. **格式**: 推荐使用WebP格式，兼容性考虑可提供PNG备选
2. **压缩**: 适当压缩以减少文件大小
3. **分辨率**: 提供2x和3x版本适配高分辨率屏幕
4. **命名**: 使用语义化命名，便于维护
