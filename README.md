# 舞蹈视频分析系统

## 项目概述
一个基于AI的舞蹈视频分析系统，能够自动分析舞蹈视频的节拍、动作和结构，并生成教学指导。

## 核心功能
1. **节拍检测** - 自动识别音乐节拍，数拍子
2. **动作识别** - 识别关键舞蹈动作，逐帧分析
3. **视频分段** - 自动识别主歌、副歌、间奏等段落
4. **文字指导** - 基于GLM-4.5V生成详细的舞蹈教学指导

## 技术架构
- **后端**: Python + FastAPI
- **前端**: React + TypeScript  
- **AI服务**: 智谱GLM-4.5V API
- **视频处理**: OpenCV + FFmpeg
- **音频分析**: librosa
- **姿态检测**: MediaPipe
